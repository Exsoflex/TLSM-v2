# Clips de señas

Aquí van los clips de video por seña, uno por archivo y con el nombre de la glosa
en mayúsculas:

```
assets/senias/HOLA.mp4
assets/senias/GRACIAS.mp4
assets/senias/A.mp4
```

`tlsm.render.RenderizadorClips` los reproduce en orden para texto → señas.
Si falta un clip, el renderizador lo informa; no inventa movimiento.

El avatar 3D de la fase 5 usará el mismo contrato (`RenderizadorSenias`) y este
directorio se mantiene como respaldo en 2D.

> No se versionan videos pesados. Se publican como Release o con Git LFS.
